# Knob Export Package

This folder is generated by `generate_knob_svgs.py --export`.

## Contents

- `Types/<knob_type>/...` contains exported knob SVG folders copied from `Knobs/Types`.
- `knobs.json` contains structured metadata for all knob types and variants.
- `README.md` (this file) explains import and naming conventions.

## Import Flow (Other App)

1. Load `knobs.json`.
2. Choose a `knob_type` entry.
3. Read `variants[]` and pick the best match by `diameter_mm`, `color`, `shaft_type`, or SKU.
4. Use `variant.svg_path` when a per-diameter file exists, otherwise use `variant.template_svg_path` and scale at runtime.

## Naming System

SVG naming follows `SVG_NAMING_GUIDE.md`:

- IDs/labels use lowercase + underscores.
- Semantic swatch labels use forms like `color:primary`, `color:primaryLight`, `color:secondary`.
- Gradient labels follow `gradient:<code>` where:
  - `h`, `v`, `r` = horizontal / vertical / radial
  - `l`, `m`, `d` = light / mid / dark stops
- Invert-aware elements use `_invert` suffix, e.g. `indicator_line_invert`.
- Repeated parts use numbered suffixes (`tick_01`, `number_01`, ...).

## Color Metadata

Each variant includes:

- `color`: human-readable color name (e.g. "Black", "Light Blue", "Metallic").
- `primaryColor`: hex value for the knob's primary/body color (e.g. `"#050505"`).
- `secondaryColor`: hex value for the secondary/accent color (e.g. `"#888888"`).
- `primaryDarkColor` *(optional)*: hex value for the dark shade of the primary color.
  Only present when manually set (i.e. auto-derive was disabled in the tester).
- `primaryLightColor` *(optional)*: hex value for the light shade of the primary color.
  Only present when manually set.
- `available_colors`: normalized list like:
  - `[{"black": "#050505"}, {"white": "#ffffff"}]`

When `primaryDarkColor` / `primaryLightColor` are absent, derive them from `primaryColor`
using a darkening/lightening algorithm of your choice.

Unknown color names fall back to `#888888` and should be overridden by your app if needed.

## Runtime Scaling

Templates are normalized to 10 mm. To scale dynamically:

- scale factor = `target_diameter_mm / 10`
- apply factor to SVG `width` and `height`
- keep `viewBox` unchanged
